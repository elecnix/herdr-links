## Herdr navigation references

When `HERDR_ENV=1`, make reported live agent, workspace, tab, and shell-pane references clickable. Obtain current IDs from the invoking Herdr session, then run `node "@PLUGIN_ROOT@/dist/cli.js" link <agent|workspace|tab|pane> <ID> --label "<ID> — <short description>" --scheme https` and copy its Markdown output verbatim (not in code formatting). Prefer `--scheme https`. The reserved `https://herdr.invalid` host is unroutable, so a click that misses the plugin opens a browser error page instead of leaking the request to a real site, which is the safe failure mode for a link an agent prints. The scheme is not what decides whether the link is clickable; the harness emitting a hyperlink at all is. Generation is read-only; do not focus a target just to report it. Use pane IDs for agents, never `terminal_id`; use `pane` for ordinary shell splits. Agent references validate detected-agent membership and then use exact pane focus so the visible Herdr 0.9 surface follows. Never invent URLs, reuse an old link after a socket/session restart, or select another socket to make an ID resolve. If verification fails, report plain text with the limitation.

Tell the user **Control + left-click**, including on macOS. Command-click belongs to the outer terminal and opens a browser instead. If the links render as plain text rather than clickable, the harness is not emitting hyperlinks at all: it emits them only for terminals it recognizes, and Herdr clears `TERM_PROGRAM` in pane shells, so set `FORCE_HYPERLINK=1` in the harness environment. If a browser opens or navigation fails, do not reuse the link: verify Herdr mouse capture is enabled, regenerate it for the current socket/version, and inspect `herdr plugin log list --plugin herdr-links --limit 5`. A click that never reaches the plugin leaves no log entry, so an empty log means the click did not arrive rather than that the handler failed. Links are only for navigation within the generating Herdr session, not cleanup permission. Tab/workspace links select that location's existing pane; only agent/pane links select an exact split. Outside Herdr, use plain IDs. No global rules or terminal settings should be changed for this convention.
